## Canvas UI

The cursor-follow reflection uses the time-based exponential easing approach in the Canvas UI Glass vanilla component, adapted to update the existing TradeLog DOM cards without capturing or redrawing the page.

- Project: <https://github.com/DavidHDev/canvas-ui>
- Component reference: <https://canvasui.dev/docs/components/glass>
- License: MIT + Commons Clause, copyright David Haz. The complete license is available in the upstream repository's `LICENSE.md`.

No Canvas UI component bundle or shader source is included in this app. The normal HTML remains the rendered and interactive interface, with `prefers-reduced-motion` support.
